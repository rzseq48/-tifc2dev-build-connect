# Build and Connect Lab

## Backend
```bash
cd backend
python -m pip install -r requirements.txt
python run.py
```

## Tests
```bash
cd backend
python -m pytest tests/test_ticket_routes.py
```

## Frontend
```bash
cd frontend
npm install
npm run dev
```
